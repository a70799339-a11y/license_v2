# 01 · 系统功能说明（ver0.1.0）

> 酒店 AI 管理 License 授权管理系统 —— 服务商内部后台 + 酒店桌面客户端
> 更新：2026-11-06（v0.2.1）

## 系统构成

| 端 | 使用者 | 入口 | 技术栈 |
|---|---|---|---|
| 管理后台 | 服务商运营团队 | http://localhost | Vue3 + Element Plus + FastAPI + PostgreSQL |
| 酒店客户端 | 各酒店（被授权方） | 桌面「酒店AI管理客户端.exe」 | Tauri v2 + Rust license-core |
| 客户端同步 API | 客户端调用 | /api/client/* | Ed25519 签发 + JWT + 心跳 |

## 总/子管理（集团）

| 能力 | 说明 |
|---|---|
| 集团实体 | 集团码（GP-xxxx）+ 旗下 N 家门店归属关系，种子 9 个集团 |
| **客户端总端形态** | 用集团码激活进入「集团总端」：集团 KPI（门店/设备/到期/告警）、门店一览（勾选批量续期）、跨店告警、心跳同步 |
| **客户端门店形态** | 门店授权码激活（原有能力）：只见自己 |
| 后台集团管理页 | 集团列表、创建集团（签发集团码）、集团详情（成员/划入门店/全部续期） |
| 数据隔离 | 集团总端只见本集团门店与告警；单店 token 调集团接口拒绝 |

同一客户端 exe 按激活码自动区分形态（GP- 开头 = 集团总端，否则 = 门店）。

## 权限分角色（P2）

| 角色 | 账号（种子） | 权限 |
|---|---|---|
| admin 管理员 | admin / admin123 | 全部操作，含设置、用户管理 |
| operator 运营 | ops / ops123 | 客户/授权/续期/告警处置（不能改设置、管用户） |
| viewer 只读 | viewer / viewer123 | 仅查看，写操作按钮隐藏且后端 403 |

后端 `require_roles()` 守卫 + 前端按钮显隐 + 路由守卫（/users 仅 admin）。

## 酒店客户端功能

- **激活**：授权码（LIC-xxxx / HT-xxxx）+ 设备指纹绑定，Ed25519 验签通过才落盘
- **授权概览**：套餐、状态、到期倒计时、自动续期
- **设备信息**：本机指纹 + 本酒店绑定设备
- **同步状态**：60s 自动心跳 + 手动同步、检查更新（版本联动）、服务端地址、退出激活
- **安全内核（license-core）**：设备指纹、验签、AES-256-GCM 加密存储、时钟回滚检测、反调试门禁
- **自检**：`hotel-client.exe --selftest HT-0001` 一条命令跑完整激活链路

## 实时告警管道（检测 → 自动记账）

风控页告警由检测点**真实自动产生**（24h 去重），不再是演示数据：

| 检测事件 | 触发点 | 告警规则 | 等级 |
|---|---|---|---|
| 凭证挪机/指纹不一致 | 心跳校验 | 设备指纹变更 | 高 |
| 客户端时钟回滚 | 心跳上报异常 | 时间回滚 | 高 |
| 同店 24h 内 ≥3 台设备激活 | 激活计数 | 多设备并发激活 | 高 |
| 中断超宽限后恢复 / 在册停摆 | 心跳间隔 + 惰性扫描 | 心跳中断 | 中 |
| 无效授权码激活尝试 | 激活失败 | 无效激活尝试 | 中 |
| 设备数达上限仍激活 | 激活被拒 | 设备数超限 | 中 |
| 吊销/过期授权仍在心跳 | 心跳校验 | 吊销后使用 | 紧急/高 |

## 大模型接入（云端 + 本地）

风控页告警「AI 解读」与企微机器人 AI 问答由大模型生成；**云端 API（DeepSeek/腾讯混元等）与本地（Ollama/llama.cpp）双配置并存**，可切换、可互为兜底，后台可配。所有调用经服务端审计网关留痕。

## 大模型调用审计（v0.2.1+）

集团/门店/后台经服务端网关的每次大模型调用全量留痕（调用来源、发起人、用户输入、模型输入/输出、token、耗时），文本自动脱敏；查看入口：后台-安全设计-大模型调用审计。所有 LLM 调用必须过服务端网关（客户端不直连模型）。

## 离线宽限期（超时禁用 / 联网恢复）

| 机制 | 说明 |
|---|---|
| 宽限期 | 客户端离线后可继续使用；以**自己最后一次成功同步**倒计时 |
| 超时禁用 | 超过宽限时长（默认 **72 小时**）进入锁定态：全功能禁用 + 锁定遮罩，仅留「重新连接」 |
| 联网恢复 | 心跳成功即自动解锁，无需联系服务商 |
| **服务端统一配置** | 后台「安全设计」页配置小时数（1–8760），随心跳下发全部客户端（门店端+集团端）；集团无需也不能设置 |

自检命令：`hotel-client.exe --selftest-offline`（激活→离线→超时锁定→恢复 全链路）。

## 与后端同步更新机制

| 机制 | 说明 |
|---|---|
| 心跳 | 60s/次：吊销、到期、停用、自动续期即时下发 |
| 版本同步 | 心跳/检查更新返回 update_available + 下载地址；管理端 settings.client_version 发布新版提示 |
| 自助数据 | profile 仅返回本酒店设备/授权/告警 |
