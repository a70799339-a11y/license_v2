# 07 · 子酒店（门店）配置指南

> **读者：单体酒店 / 门店管理员。** 集团总部另有《06-集团总端配置指南》；服务端由服务商运维，无需关心。
> 更新：2026-11-06 ｜ 适用客户端版本：v0.2.1+

本指南教你在酒店电脑上安装客户端、激活授权、配好企微通知。全程约 5 分钟。

---

## 一、你会从服务商拿到什么

| 物品 | 形式 | 用途 |
|---|---|---|
| **授权码**（LIC-xxxx 或 HT-xxxx） | 由服务商签发 | 激活客户端（一机一码） |
| 客户端安装包 | `酒店AI管理客户端_x.x.x_x64-setup.exe` | 装在酒店前台/办公电脑 |
| 服务端地址 | 如 `https://license.你们公司.com` | 激活时填写 |

> 属于某集团的门店同样用**自己的授权码**激活（不是集团码）；集团看你们是集团的事，不影响门店用法。

---

## 二、安装与激活（3 分钟）

1. 双击安装包 → 桌面出现「酒店AI管理客户端」
2. 打开客户端，激活页填三项：
   - **服务端地址**：服务商给的地址
   - **授权码**：你的授权码
   - **设备名称**：如「前台电脑」
3. 点「激活」→ 看到「激活成功」即完成

激活会绑定这台电脑（防止授权被拷走）。**重装系统/换电脑**：新电脑重新激活即可恢复，无需找服务商。

---

## 三、日常使用（三个页签）

| 页签 | 看什么 |
|---|---|
| **授权概览** | 套餐、授权状态、到期倒计时、自动续期开关 |
| **设备信息** | 本机指纹 + 本店全部绑定设备清单 |
| **同步状态** | 心跳同步（60 秒自动）、检查更新、消息通知配置、服务端地址 |

无需手动操作——客户端**每 60 秒自动与服务端同步**（续期/吊销/版本更新都会自动生效）。

---

## 四、配置企微群通知（推荐）

让本店的告警与到期提醒自动推到你们的企微群：

1. 企微群 → 群设置 → 添加群机器人 → 复制 **webhook 地址**
2. 客户端 → **同步状态 → 消息通知** → 粘贴 webhook → 保存 → 点「发送测试消息」
3. 测试消息出现在群里即配置成功，之后自动推送

> 只支持企业微信官方机器人地址（`qyapi.weixin.qq.com/.../send?key=...`）；乱填的地址会被拒绝（安全校验）。

---

## 五、断网了怎么办（离线宽限）

断网后客户端**照常可用**，从最后一次成功同步开始倒计时：

- **72 小时内**（服务商可调）：正常用，顶部横幅提示剩余时间
- **超过时限**：功能锁定，只剩「重新连接」按钮
- **恢复联网**：自动解锁，立即恢复正常

也就是说：短期断网/检修不影响营业；长期断网（如超过 3 天）需要联网恢复一下。

---

## 六、常见问题

| 问题 | 解决 |
|---|---|
| 激活报 404 / 网络请求失败 | 核对服务端地址；等几秒重点一次（客户端自动重试 3 次） |
| 激活报「授权已吊销/过期」 | 联系服务商核对授权状态 |
| 激活报「设备已绑定其他酒店」 | 这台电脑被别的店绑过；换电脑激活或联系服务商解绑 |
| 提示「发现新版本」 | 下载新安装包覆盖安装即可（授权与配置不丢） |
| 想换电脑使用 | 新电脑装客户端、用同一授权码激活（旧设备自动失效） |
| 客户端提示「功能已禁用」 | 断网超时了——联网后点「重新连接」自动恢复 |
| 授权快到期 | 联系服务商续期；续期后客户端心跳自动显示新到期日 |
