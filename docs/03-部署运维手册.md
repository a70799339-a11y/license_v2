# 03 · 部署运维手册

> 本机 WSL 测试环境 + 正式服务器部署通用说明
> 更新：2026-11-04

## 一、当前测试环境（WSL Ubuntu 24.04）

| 组件 | 位置 | 说明 |
|---|---|---|
| PostgreSQL 16 | WSL 内 systemd: postgresql | 库 license，连接串见后端环境变量 |
| FastAPI 后端 | WSL 内 systemd: license-backend | :8000，单进程托管 API + 前端静态文件 |
| Nginx | WSL 内 systemd: nginx | :80 → uvicorn:8000，入口 http://localhost |
| 前端产物 | /opt/license/backend/static | npm run build 后拷入 |
| 签名私钥 | /opt/license/backend/keys/ed25519.key | FileKeyProvider，权限 600 |

### 日常命令

```bash
# 保活（防 WSL 休眠导致 404/502）
wsl -d Ubuntu-24.04 -u root -e sleep infinity

# 服务管理
wsl -d Ubuntu-24.04 -u root -e systemctl {status|restart} license-backend postgresql nginx

# 看后端日志
wsl -d Ubuntu-24.04 -u root -e journalctl -u license-backend -n 50

# 回归测试（走 Nginx 入口）
BASE_URL=http://localhost python tests/run_tests.py
```

### 已知注意事项

- **WSL 空闲休眠**：虚拟机睡着后 wslrelay 对请求回 404（客户端已内置 3 次自动重试）；长时间使用请挂保活
- 前端更新后需拷贝 `dist/` → `/opt/license/backend/static` 并 restart license-backend

## 二、正式服务器部署（物理机/云主机）

前提：Linux x86_64（Ubuntu 22.04+ / CentOS 9+）、Python 3.11+、PostgreSQL 14+。

```bash
# 1. 取代码（含 backend/ deploy/ docs/）
# 2. 装依赖
python3 -m venv .venv && .venv/bin/pip install -r backend/requirements.txt \
    -i https://mirrors.aliyun.com/pypi/simple/

# 3. 配置环境变量（systemd unit 或 .env）
DATABASE_URL=postgresql+psycopg2://user:pass@127.0.0.1:5432/license
JWT_SECRET=<强随机串>                 # 必改
LICENSE_KEY_PROVIDER=file             # 或 env/kms（见 02-安全加固指南）
# LICENSE_SIGNING_KEY=                # 仅 env 模式需要

# 4. 建库 + 启动（首次启动自动建表 + 种子数据）
createdb license
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000

# 5. 前端产物
npm run build && cp -r dist/* backend/static/

# 6. systemd + Nginx 参考 deploy/license-backend.service 与 deploy/nginx.conf
```

### 生产必做清单

- [ ] 改 JWT_SECRET、数据库密码
- [ ] Nginx 配 HTTPS（Let's Encrypt / 机构证书）
- [ ] 收敛 CORS（allow_origins 改为正式域名）
- [ ] 数据库每日备份（pg_dump + 异地）
- [ ] 日志轮转（journald 或 logrotate）
- [ ] 私钥文件权限 600 + 备份加密存放

## 三、客户端分发

| 形态 | 产出 | 适用 |
|---|---|---|
| NSIS 安装包 | client/src-tauri/target/release/bundle/nsis/*-setup.exe | 酒店正式安装（桌面/开始菜单/卸载项） |
| 绿色便携版 | hotel-client.exe 直接拷贝 | 快速试用/批量部署 |
| 版本更新 | 管理端 settings.client_version 提示 + 下发新安装包 | 和后端同步更新 |

客户端服务器地址可在「同步状态」页修改（默认 http://localhost，生产填正式域名）。

## 四、故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 客户端报 404 | WSL/服务休眠或服务未启动 | 启动服务 + 保活；客户端会自动重试 |
| 客户端报「License 验签失败」 | 服务端私钥轮换过 | 重新激活 |
| 客户端报「设备已绑定其他酒店」 | 指纹冲突 | 管理端解绑旧设备或换机激活 |
| 客户端提示「功能已禁用」 | 离线超过宽限时长（默认 72h） | 连网点「重新连接」自动恢复；时限在后台-安全设计可调 |
| 后端 500 激活 | 设备数达套餐上限/字段超长 | 看 journalctl 日志定位 |
| 打开后台 502 | uvicorn 未启动 | systemctl restart license-backend |
