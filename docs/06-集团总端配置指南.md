# 06 · 集团总端配置指南

> **读者：集团总部管理员（管旗下多家酒店）。** 子酒店请看 `07-子酒店配置指南.md`；服务端由服务商运维，无需关心。
> 更新：2026-11-06 ｜ 适用客户端版本：v0.2.1+

本指南教你在集团总部电脑上安装「酒店AI管理客户端」并进入**集团总端**，统一查看和管理旗下所有门店。

---

## 一、你会从服务商拿到什么

| 物品 | 形式 | 用途 |
|---|---|---|
| **集团码**（GP-xxxx） | 由服务商签发 | 激活集团总端（区分于门店授权码） |
| 客户端安装包 | `酒店AI管理客户端_x.x.x_x64-setup.exe` | 装在集团总部电脑上 |
| 服务端地址 | 如 `https://license.你们公司.com` | 激活时填写（内网部署为服务商给的地址） |

> 集团码只给总部一份，**不要下发给门店**——门店用各自的授权码（见 07）。

---

## 二、安装与激活（5 分钟）

1. 双击安装包 → 桌面出现「酒店AI管理客户端」
2. 打开客户端，在激活页填三项：
   - **服务端地址**：服务商给的地址
   - **授权码**：填 **集团码 GP-xxxx**
   - **设备名称**：如「集团总部-运营部」
3. 点「激活」→ 成功后自动进入**集团总端**界面

激活即完成设备绑定（一机一店）。重装系统/换电脑：重新激活即可，配置在服务端不丢。

---

## 三、集团总端能做什么

| 功能 | 说明 |
|---|---|
| **集团 KPI** | 门店数、设备总数、到期门店数、告警数一屏总览 |
| **门店一览** | 旗下每家店的授权状态/套餐/设备数/到期日；勾选后**批量续期**或**全部续期一年** |
| **跨店告警** | 旗下门店的风险告警汇总（设备指纹变更/吊销后使用等） |
| **同步状态** | 60 秒自动心跳 + 手动同步；检查新版本；退出激活 |

**数据边界**：总端只见**本集团**门店与告警，看不到其他集团/单店客户的数据（服务端强制隔离）。

---

## 四、配置企微群通知（推荐）

让集团的风控告警/日报自动推到你们的企微群：

1. 企微群 → 群设置 → 添加群机器人 → 复制 **webhook 地址**
2. 客户端 → **同步状态 → 消息通知** → 粘贴 webhook → 保存 → 点「发送测试消息」验证
3. 之后本集团告警（紧急/高）与日报自动推该群

> 只支持企业微信官方机器人地址（`qyapi.weixin.qq.com`）；配置存服务端，换电脑不丢。

---

## 五、企微机器人（群里 @机器人 管店）

集团管理员可绑定服务商的企微智能机器人，在企微里直接查/管：

1. @机器人 发任意消息 → 把回复里的 **userid** 发给服务商
2. 服务商绑定后（角色 group，只能操作本集团）即可使用：

| 指令/提问 | 效果 |
|---|---|
| `状态 HT-0001` | 查某店授权状态/到期/设备 |
| `告警 HT-0001` | 查某店最近告警 |
| `续期 HT-0001` → 回复`确认续期 HT-0001` | 续期一年（二次确认防误触） |
| 其他任何问题 | **AI 直接回答**（自动带上你集团的门店概况） |

---

## 六、离线宽限（断网怎么办）

客户端断网后**仍可继续使用**，以本机最后一次成功同步开始倒计时（时限由服务商统一配置，默认 **72 小时**）：

- 宽限期内：正常用，顶部横幅显示剩余时间
- 超过时限：功能锁定（只留「重新连接」）→ **恢复联网后自动解锁**，无需联系服务商
- 时限是服务商全局配置，集团无需也不能自行调整

---

## 七、常见问题

| 问题 | 解决 |
|---|---|
| 激活报 404/网络失败 | 确认服务端地址正确；稍等几秒重试（客户端会自动重试 3 次） |
| 激活报「授权码无效」 | 核对集团码是否 GP- 开头、有无抄错；联系服务商 |
| 新开的门店看不到 | 门店需服务商在后台划入本集团（或由我们授权你自助划入） |
| 想换电脑用总端 | 新电脑装客户端、用同一集团码激活即可（旧机自动解绑或联系服务商） |
| 看到「发现新版本」 | 按提示下载新安装包覆盖安装（配置不丢） |
